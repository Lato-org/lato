User Management

Full authentication system with signin, signup, password recovery, email validation, Google Authenticator and WebAuthn (passkeys) MFA, and ETH wallet connection.

Customizable & Extendable

The gem is designed to be easily customizable and extendable. You can fully customize the UI and functionalities, add new features to your main application, or develop new engines to extend the panel.

Accessible by Design

Keyboard friendly, screen reader aware components audited with axe-core against WCAG 2.2 AA rules. Accessibility comes built in, not as an afterthought.

Quick start

Installation

Up and running in a few minutes, in any Rails 8.1 application.

  1. 1

    Add Dependencies

    Add required dependencies to your application's Gemfile:

    # Use JavaScript with ESM import maps [https://github.com/rails/importmap-rails]
gem "importmap-rails" # NOTE: Probably already installed in default Rails 8 project

# Hotwire's SPA-like page accelerator [https://turbo.hotwired.dev]
gem "turbo-rails" # NOTE: Probably already installed in default Rails 8 project

# Hotwire's modest JavaScript framework [https://stimulus.hotwired.dev]
gem "stimulus-rails" # NOTE: Probably already installed in default Rails 8 project

# Use Sass to process CSS
gem "sassc-rails"

# Use lato as application panel
gem "lato"

    Lato stores rate limits and verification codes in Rails.cache: use a persistent cache shared across processes (Redis, Solid Cache, Memcached). Wallet login (Web3) also requires gem "eth" in your Gemfile.

  2. 2

    Configure Asset Manifest

    If not already present, add app/assets/config/manifest.js file with the following content:

    //= link_tree ../images
//= link_directory ../stylesheets .css
//= link_tree ../../javascript .js
//= link_tree ../../../vendor/javascript .js
  3. 3

    Install and Setup

    Install gem and run required tasks:

    $ bundle
$ rails active_storage:install
$ rails lato:install:application
$ rails lato:install:migrations
$ rails db:migrate
  4. 4

    Configure Routes

    Mount lato routes on the config/routes.rb file:

    Rails.application.routes.draw do
  mount Lato::Engine => "/lato"

  # ....
end
  5. 5

    Import Styles

    Import Lato Scss on app/assets/stylesheets/application.scss file:

    @import 'lato/application';

// ....
  6. 6

    Import JavaScript

    Import Lato Js on app/javascript/application.js file:

    import "lato/application";

// ....
  7. 7

    Setup I18n

    Setup I18n on the config/application.rb file:

    module MyApplication
  class Application < Rails::Application
    config.i18n.available_locales = [:it, :en]
    config.i18n.default_locale = :it

    # ...
  end
end

    Lato ships translations for it, en, fr and ro. Any key can be overridden in your application locale files. Emails are available in Italian and English (other locales receive English).
